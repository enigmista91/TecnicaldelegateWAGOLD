# WA Gold TD Dashboard - Promo Video Generator

Questa cartella contiene un progetto [Remotion](https://www.remotion.dev/) per generare programmaticamente video promozionali (o tutorial) per la Dashboard.

## 🚀 Come usarlo

1. Assicurati di avere Node.js installato.
2. Apri il terminale in questa cartella e installa le dipendenze:
   ```bash
   npm install
   ```
3. Per avviare l'Editor Visivo in tempo reale nel browser e modificare i testi/animazioni:
   ```bash
   npm start
   ```
4. Per esportare (renderizzare) il file MP4:
   ```bash
   npm run build
   ```

## 🛠 Modificare il video
Il codice sorgente del video si trova in `src/PromoVideo.jsx`. Puoi cambiare i testi, i colori e la durata delle animazioni o aggiungere nuove "scene" per le nuove release!
